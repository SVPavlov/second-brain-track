Sessie 3 · pad A · uitgebreide handleiding

WhatsApp aan je brein koppelen

Volledige versie van slide 8, voor als je dit nog nooit gedaan hebt. Per stap: wat je typt, wáár je het typt, en wat je hoort te zien. Duurt 45 tot 60 minuten. Doe het met je buddy.

0Kies eerst eerlijk (30 seconden)

Jouw situatieAdvies
Mac, of eigen Linux-laptopPrima. Begin bij stap 1.
Windows, eigen laptop, installatierechtenKan, met één extra horde (zie het rode blok bij stap 2).
Windows-werklaptop met beperkte rechtenKies vandaag pad B. Dit lukt niet in een uur. Pad A kan thuis of in een peer-sessie alsnog.

Wat je gaat bouwen, in gewone taal: twee dingen. (1) Een bruggetje dat op jouw laptop draait en meeleest met jouw WhatsApp (zoals WhatsApp Web dat ook doet). Je berichten blijven op je eigen machine staan. (2) Een koppeling zodat Claude dat bruggetje vragen kan stellen.

1Gereedschap installeren

Open je terminal. Mac: druk Cmd+spatie, typ "Terminal", Enter. Windows: startmenu, typ "PowerShell", Enter.

Check wat je al hebt. Typ deze twee regels (na elke regel Enter):

go version
uv --version
Wat je hoort te zien: iets als go version go1.22... en uv 0.5.... Zie je dat bij allebei? Ga naar stap 2.

Krijg je "command not found" (of "niet herkend")? Installeer wat mist:

  • Go: ga naar go.dev/dl, download de installer voor jouw systeem, klik hem door.
  • uv (Mac/Linux): plak in je terminal: curl -LsSf https://astral.sh/uv/install.sh | sh
  • uv (Windows, in PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
Belangrijk: sluit na het installeren je terminal en open een nieuwe. Anders "ziet" je terminal de nieuwe programma's niet (dit was dé muur van sessie 1). Doe daarna de twee checks opnieuw.
✅ Checkpoint 1 gehaald (beide checks geven antwoord)? Post "✅ 1" in de groep.

2Het bruggetje starten + QR scannen

Plak deze drie regels één voor één in je terminal (na elke regel Enter, wacht tot hij klaar is):

git clone https://github.com/lharries/whatsapp-mcp.git
cd whatsapp-mcp/whatsapp-bridge
go run main.go
Alleen Windows: doe vóór go run main.go eerst eenmalig go env -w CGO_ENABLED=1. Krijg je daarna een fout over "go-sqlite3 requires cgo"? Dan heb je ook een C-compiler nodig: installeer MSYS2 en zet de map ucrt64\bin in je PATH. Is dat je te veel voor nu: wissel naar pad B, dit komt later wel.
Wat je hoort te zien: eerst wat logregels, dan een grote QR-code van blokjes in je terminal.

Pak je telefoon: WhatsApp → Instellingen → Gekoppelde apparaten → Apparaat koppelen → scan de QR-code op je scherm.

Daarna zie je: "Successfully authenticated" of "Connected to WhatsApp". De eerste keer haalt hij je berichtgeschiedenis op; dat kan een paar minuten duren. Laat dit terminalvenster open staan — het bruggetje moet blijven draaien.
✅ Checkpoint 2 gehaald (QR gescand, connected)? Post "✅ 2" in de groep. Koffie verdiend.

3Claude aan het bruggetje koppelen

Open een NIEUW terminalvenster (het oude blijft het bruggetje draaien). Zoek eerst uit waar de map staat. Typ:

cd whatsapp-mcp
pwd
Wat je hoort te zien: een pad, bijvoorbeeld /Users/jenaam/whatsapp-mcp. Dat pad heb je zo nodig.

Ga nu naar je brein-map (bijvoorbeeld cd ~/second-brain, waar je normaal Claude start) en plak dit, met JOUW pad van hierboven erin:

claude mcp add whatsapp -- uv --directory /JOUW/PAD/whatsapp-mcp/whatsapp-mcp-server run main.py

Dus als pwd zei /Users/anna/whatsapp-mcp, dan wordt het: --directory /Users/anna/whatsapp-mcp/whatsapp-mcp-server

Start daarna een nieuwe Claude-sessie in je brein-map (typ claude).

Check: typ in Claude /mcp — staat er "whatsapp" bij met een groen bolletje? Dan zit hij erop.
✅ Checkpoint 3 gehaald? Post "✅ 3" in de groep.

4De eerste vraag

Vraag in diezelfde Claude-sessie:

Zoek in mijn WhatsApp de laatste berichten in [naam van een groep]
en vat samen wat er speelt.
Wat je hoort te zien: Claude vraagt toestemming om een whatsapp-tool te gebruiken (zeg ja), en geeft dan een samenvatting van échte berichten uit die groep.

Lege antwoorden? De eerste sync is misschien nog bezig: probeer het over een kleine, rustige groep, of wacht twee minuten.

✅ Checkpoint 4 gehaald? Gefeliciteerd, je brein leest zelf. Post "✅ 4" + een screenshot in de groep!

!Als het vastloopt

  • "command not found" na installeren → terminal sluiten en nieuw venster openen (echt).
  • Geen QR-code te zien → maak je terminalvenster groter en start go run main.go opnieuw.
  • "Device limit reached" → telefoon: Gekoppelde apparaten, verwijder een oud apparaat.
  • Fout over go-sqlite3 / cgo (Windows) → zie het rode blok bij stap 2.
  • Het werkte, maar later niet meer → de koppeling verloopt na ~20 dagen; dan opnieuw de QR scannen (stap 2).
  • Halverwege het bouwuur en nog geen QR gezien? → wissel naar pad B. Geen falen; dit komt in een peer-sessie terug.

De regels

  • Je berichten blijven lokaal op je eigen machine; er gaat pas iets naar Claude als jij een vraag stelt.
  • Je appjes bevatten klantdata en privégesprekken: wat je brein ervan in notities zet valt onder de gewone data-regel (geen klantnamen in wat je deelt).
  • Laat je brein nooit ongezien acties uitvoeren op basis van binnenkomende berichten. Jij blijft de gate.
